# How to edit the philosophy page

1. Open [src/pages/about/philosophy.astro](../src/pages/about/philosophy.astro).
2. Edit the HTML headings, paragraphs, and lists inside `<Layout>`. This file uses HTML, not Markdown. For example:

   ```html
   <h2>Writing</h2>
   <p>Clarity and simplicity guide my writing.</p>
   ```

3. If needed, change the layout's `title` and `description` above the content. Keep `pubDate` as the original publication date.
4. [Preview locally](preview-locally.md) at `/about/philosophy/`. Check headings, links, and text, then [deploy changes](deploy-changes.md).
