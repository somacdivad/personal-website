# David Amos

My personal website and blog at [davidamoswrites.com](https://davidamoswrites.com), built with Astro and hosted on Vercel.

To start locally, run these commands from the repository root:

```sh
npm install
npm run dev
```

Open the local URL printed in the terminal.
See the [how-to guides](docs/README.md) for writing, reading updates, and site upkeep.
